# 40+ Income

Landing page statique pour un site de revenus et de monétisation pour les personnes de 40 ans et plus.

## Aperçu

Cette petite landing page en HTML/CSS/JS présente une proposition de marque et un design premium pour un site orienté vers la monétisation de l'expérience, des compétences et du réseau.

## Démarrage

Ouvrez simplement `index.html` dans le navigateur.

Vous pouvez aussi lancer un petit serveur local si vous voulez un rendu plus proche d’un site réel :

```bash
python3 -m http.server 8000
```

Puis ouvrez :

```text
http://localhost:8000
```

## Structure

- `index.html` : page principale
- `style.css` : styles et responsive design
- `script.js` : petit script d’interaction

## Personnalisation

Vous pouvez modifier :
- le texte de la marque
- les offres de tarification
- la palette de couleur
- le contenu marketing
- les liens CTA

## Objectif

Le site vise à présenter une image sérieuse, premium et orientée résultats pour des adultes de 40 ans et plus qui souhaitent créer ou développer un revenu complémentaire ou principal.
